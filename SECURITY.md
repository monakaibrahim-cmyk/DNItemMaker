# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within DNItemMaker (e.g. buffer overflows in DNT binary parsers, malicious DDS injection vectors, or memory safety violations), please report it responsibly:

1. **Do not create a public issue**.
2. Contact the maintainer privately via GitHub security advisories at https://github.com/monakaibrahim-cmyk/DNItemMaker/security/advisories.
3. Include detailed reproduction steps, the target file/payload if applicable, and system environment details.
4. We aim to acknowledge receipt within 48 hours and provide a patch in a timely manner.
